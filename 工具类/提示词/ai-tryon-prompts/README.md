# 用开源服装图库做电商图：选图 + 试穿提示词 + 核对清单

> 图库：拍片哥女装（github.com/paipiange/nvzhuang，在线预览 paipiange.github.io/nvzhuang），2,727 套 AI 生成的纯服装参考图，MIT 协议。
> 这份素材包讲怎么把它用进电商做图。提示词可以直接复制，【】里换成你自己的内容。
> 说明：以下是我们整理的方法和提示词，效果因模型和图片而异，先拿一款货小批量试。

---

## 一、先想清楚：图库在流程里放哪

```
你的真实商品图（必须有）
        ＋
图库参考图（定款式、风格、搭配方向）
        ＋
人像（自己 / 已授权的模特）
        ↓
试穿提示词 → 出图 → 对照实物核对 → 合格的才上架
```

一句话：**图库管"想要什么感觉"，你的货管"卖的是什么"。** 挂到商品页的图，衣服必须是你自己的实物。

## 二、怎么挑参考图（5 分钟）

1. **按品类和季节筛**：先在分类里选春 / 夏 / 秋 / 冬 / 派对，再搜关键词。中英文都能搜，常用词：
   - 品类：连衣裙 dress、衬衫 shirt、外套 coat、针织衫 knit、半身裙 skirt、裤 pants
   - 元素：蕾丝 lace、碎花 floral、格纹 plaid、收腰 waist、泡泡袖 puff sleeve
   - 颜色：白 white、黑 black、米色 beige、藏青 navy
2. **挑和你的货"同品类、同版型"的**：你卖直筒裤，就别拿阔腿裤当参考。
3. **挑正面完整、版型清楚的**：领口、袖口、下摆都看得到的图，模型更好理解。
4. **一次只用一套参考**：多套混在一起，模型容易把元素拼乱。
5. **对外展示只用日常款**：泳装、内衣、性感类不要放进主图和宣传图，平台审核容易出问题。

## 三、虚拟试穿提示词

### 3.1 英文原版（来自 OpenAI 官方 GPT Image 提示词指南的试穿示例）

适合 GPT Image 系列，也可以直接给其他支持英文的生图模型。附两张图：人物图、服装图。

```
Edit the image to dress the woman using the provided clothing images. Do not change her face, facial features, skin tone, body shape, pose, or identity in any way. Preserve her exact likeness, expression, hairstyle, and proportions. Replace only the clothing, fitting the garments naturally to her existing pose and body geometry with realistic fabric behavior. Match lighting, shadows, and color temperature to the original photo so the outfit integrates photorealistically, without looking pasted on. Do not change the background, camera angle, framing, or image quality, and do not add accessories, text, logos, or watermarks.
```

用法：人物是男性就把 the woman / her 换成 the man / his。

### 3.2 中文版（我们按原版意思翻的，豆包、通义等中文模型用）

```
请编辑图 1（人物照片），给图中人物换上图 2 里的服装。
不得改变人物的脸、五官、肤色、身材、姿势和身份；完整保留其样貌、表情、发型和身体比例。
只替换衣服：让服装自然贴合人物现有的姿势和身形，面料的垂坠、褶皱要真实。
光线、阴影和色温与原照片一致，服装要像真的穿在身上，不能有贴图感。
不要改变背景、机位、构图和画质；不要添加配饰、文字、logo 或水印。
```

### 3.3 用你自己的商品图（卖货版）

把图库参考图换成你的实物商品图，并把商品细节写死：

```
请编辑图 1（人物照片），给图中人物换上图 2 里的服装（这是我们的在售商品，必须忠实还原）。
【服装信息】品类：【连衣裙】；颜色：【米白】；面料：【棉麻】；版型：【收腰 A 字】；长度：【过膝】
必须保持不变的服装细节：颜色、面料质感、领口形状、袖长和袖口、腰线、下摆长度、纽扣数量和位置、印花或刺绣的位置。
不得改变人物的脸、五官、肤色、身材、姿势和身份；保留发型和表情。
光线、阴影、色温与原照片一致；不改背景、机位和构图；不加文字、logo、水印。
不要：长袖变短袖、裤子变裙子、多出或少了纽扣、颜色偏差、面料像塑料。
```

### 3.4 先定风格、再换成自己的货（两步走）

第一步，用图库参考图定一张"风格样张"：

```
参考图 2 的服装风格（款式、配色、搭配方式），为图 1 的人物生成一张【通勤 / 街拍 / 居家】风格的穿搭照，9:16 竖版，自然光，真实手机摄影感。
不得改变人物的脸、五官、肤色、身材和身份。不要文字和水印。
```

第二步，样张满意后，用 3.3 把衣服换成你的实物，只改衣服，其他都不动。

## 四、保持脸和身材不变：写法要点

换装最常见的翻车：脸变了、变瘦了、背景也跟着变了。写提示词时把这几条每次都带上：

- **列出不许动的**：脸、五官、肤色、身材、姿势、发型、表情、背景、机位、构图、画质。
- **说清只改什么**："只替换衣服"。
- **一次只改一件事**：第一次只换衣服；要换背景，下一轮单独换，并把"不许动"那几条再说一遍。
- **图片编号**：多张图时写"图 1 是人物、图 2 是服装"，别让模型猜。
- **人像照片要清楚**：正面或微侧、全身或至少到膝、光线均匀、没有遮挡；人像越清楚，脸越稳。
- **跑偏了别加长提示词**：回到原图重新来，比在跑偏的图上继续改稳。

## 五、出图后核对清单（上架前逐项打勾）

对照实物或商品原图：

- [ ] 颜色：和实物一致，没有偏色
- [ ] 领口：形状、高低正确
- [ ] 袖子：长短、袖口样式正确
- [ ] 腰线和版型：收腰 / 宽松没变
- [ ] 长度：衣长、裙长、裤长正确
- [ ] 纽扣、拉链：数量和位置正确
- [ ] 印花、刺绣、logo：位置和图案正确，没有乱码
- [ ] 人物：脸没变、手指正常、没有多余的肢体
- [ ] 背景：没有多出东西、没有乱码文字
- [ ] 整体：不像贴上去的

有一项不过就重出，别上架。服装细节画错，买家收到货对不上，退货和差评的风险都在你这。

## 六、换装后端怎么选（按作者 README 整理，我们未逐个实测）

| 场景 | 可选 |
|---|---|
| 国内网络、不想折腾 | 豆包 Seedream（火山方舟） |
| 已有 OpenAI 或中转 Key | GPT Image 2 |

后端用作者给的 Docker Compose 启动；部署到公网时，记得开访问 Token 和限流（作者默认 10 次/分、100 次/天）。Key 只填在你自己的设备或服务器上，不要发给别人。

## 七、商用注意（务必看完）

1. **MIT 管的是仓库里的代码和图**：作者称图集按 MIT 开源、可商用。但 README 致谢了原作者对这批图的整理，原尺寸图指向原站；大规模商用前，建议自己核一下图源。
2. **兄弟项目不是 MIT**：姿势库 ai-pose-gallery-zh 在 GitHub 上的许可证显示为 Other，商用前单独看它的说明。
3. **真人照片的授权自己拿**：上传谁的照片，就要谁同意。用模特、员工、朋友的照片，先拿到书面同意，写清用在哪些平台、用多久。不要用网上找的别人的照片。
4. **图库衣服不是在售商品**：只当款式、搭配、风格参考，不能当你的商品图卖。
5. **AI 生成内容的标识**：国内平台对 AI 生成内容有标识要求，发布时按平台提示勾选"AI 生成"或加标识，以平台当时的最新规则为准。
6. **对外展示挑日常款**：泳装、内衣、性感类不进主图和宣传图。
