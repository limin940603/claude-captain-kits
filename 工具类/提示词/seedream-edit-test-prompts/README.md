# Seedream 5.5 商品图连续修改测试提示词

客户让商品图再改一版，AI 能改对指定位置，还把产品原样留下来吗？这套清单用连续修改的方式，检查背景、文案和局部元素变化后，商品主体是否逐渐走样。最后再检查透明素材的边缘，记录每轮耗时与返工情况。本文提供待执行的测试方案，尚未进行产品实测，不代表 Seedream 5.5 已通过这些检查。

## 测试前准备

- 准备一张自有或获授权的商品图，主体清楚，保留原始文件。
- 优先使用能看清包装文字、商标、接口或其他细节的图片，方便判断修改后有没有走样。
- 把原图中必须保留的文字逐字抄下，作为核对依据；看不清的内容标为“无法判断”，不要让模型猜。
- 在同一会话中连续编辑，每轮以上一轮结果为修改对象。界面支持参考图时，同时保留原图作为主体核对依据。
- 每轮先保存首次结果，再决定是否返工。不要只保留最好的一张。
- 记录实际使用的平台、模型名称、测试日期和导出格式，避免把不同入口的结果混在一起。

先填写测试信息：

```text
界面显示的模型名称：
原始图片文件名：
商品名称：
原图中必须保持正确的文字：
必须保留的主体细节：
测试操作人：
```

## 连续修改规则

下面共 8 条提示词，按顺序使用。将 `[商品名称]` 替换为图片中的商品名称，其余内容可直接复制。

每轮提示词中的“保持不变”，都是测试要求，不是模型一定能做到的保证。检查时同时对照上一轮和原图：前者用于发现本轮误改，后者用于发现多轮累积变化。

### 第 1 轮：只换背景

检查重点：背景是否替换，商品轮廓、颜色、商标和包装文字是否被连带修改。

```text
请编辑这张商品图，把背景替换为干净的暖灰色摄影棚背景。

只修改背景。保持[商品名称]的外形、比例、颜色、材质、朝向和画面位置不变，保留商品上的商标、图案及所有可辨认文字，不增加或删除商品部件。

让商品与背景自然衔接，可以调整背景及接触阴影，但不要重画商品，不要添加装饰物或新文案。
```

### 第 2 轮：再次换背景

检查重点：连续换背景后，主体是否发生累积变形，细节是否减少。

```text
继续编辑上一轮图片，把暖灰色背景改为浅米色桌面与柔和的同色背景，营造简洁的商品展示场景。

只修改背景、桌面和必要的接触阴影。保持当前商品的大小、位置、朝向，以及与原始商品图一致的外形、颜色、材质和细节。

不要改动商标、包装文字和商品部件，不添加道具或文案。
```

### 第 3 轮：添加指定文案

检查重点：新增文字是否逐字正确，商品原有小字是否被误改。

```text
继续编辑上一轮图片，在商品旁边的背景留白处添加以下文案：

主标题：日常好物
副标题：让生活更顺手

文字必须逐字准确，不增加其他文字。使用清楚易读的深色字体，主标题比副标题醒目，文案不要遮挡商品。

除添加上述文案外，保持商品、背景、桌面、阴影和画面构图不变。不要修改商品上原有的任何文字。
```

### 第 4 轮：只改指定文案

检查重点：旧文案是否替换干净，是否出现错字、残影或其他区域误改。

```text
继续编辑上一轮图片，只替换背景留白处的广告文案：

将主标题“日常好物”改为“实用之选”。
将副标题“让生活更顺手”改为“好用，看得见”。

保持文案区域的位置、字体风格、颜色和排版关系不变。不要保留旧文案，不要增加其他文字。

商品本体、商品上的原有文字、背景、桌面及阴影都保持不变。
```

### 第 5 轮：添加局部元素

检查重点：新增元素是否放在指定区域，是否遮挡或改变商品。

```text
继续编辑上一轮图片，在商品旁边空着的桌面区域添加一片自然的绿色叶片。

叶片不要遮挡商品、商品阴影或广告文案，也不要与商品轮廓接触。如果空间不足，请缩小叶片，不要移动或缩小商品。

只添加这片叶片及其自然阴影。保持商品本体、全部文字、背景、桌面和已有构图不变。
```

### 第 6 轮：只改局部元素

检查重点：能否只修改刚添加的元素，保留相邻商品和文字。

```text
继续编辑上一轮图片，只把刚添加的绿色叶片改成自然的金黄色叶片。

保持叶片的位置、大小、形状和朝向不变，只改变叶片颜色，并使其阴影与场景一致。

不要改变商品、广告文案、背景、桌面和商品阴影，也不要添加其他元素。
```

### 第 7 轮：删除指定元素

检查重点：删除后是否留下残影、补丁，主体是否再次发生变化。

```text
继续编辑上一轮图片，删除金黄色叶片及其阴影，同时删除背景上的广告文案“实用之选”和“好用，看得见”。

自然补全这些位置的背景或桌面，不留下文字残影、叶片轮廓、色块或涂抹痕迹。

保留商品与商品原有的接触阴影。商品的外形、比例、颜色、材质、朝向、位置以及商品上原有的商标和文字全部保持不变。
```

### 第 8 轮：输出透明素材

检查重点：是否获得真实透明背景，以及主体边缘、孔洞、细小结构和文字是否保留。

```text
继续编辑上一轮图片，移除全部背景、桌面及外部投影，只保留商品本体，输出带真实透明通道的商品素材。

保持商品的外形、比例、颜色、材质、朝向和当前画面位置不变，保留商标、原有文字、细小结构和镂空区域。

不要把白色、灰色或棋盘格画成背景，不要添加描边或光晕，不要裁掉商品边缘。商品本身的透明或半透明部件应保留合理的透明效果。

如当前入口无法输出真实透明通道，请明确说明，不要用绘制的棋盘格代替。
```

## 核对时具体看什么

| 检查项 | 核对方法 | 需要记录的问题 |
|---|---|---|
| 主体变形 | 将结果与原图并排查看，重点比较轮廓、比例、商标及部件位置 | 拉伸、弯曲、部件增减、颜色漂移、纹理变化 |
| 小字正确 | 对照测试前抄下的原文，逐字检查；新增文案单独核对 | 错字、漏字、多字、字符变形、文字变模糊 |
| 修改范围 | 对照上一轮，检查指定区域之外的内容 | 背景修改牵连商品、改文案牵连包装、改叶片牵连阴影 |
| 透明边缘 | 确认文件有透明通道，再分别放到浅色和深色背景上查看 | 假透明、白边、黑边、缺口、残留背景、细节误删 |
| 耗时 | 记录生成等待、人工检查及追加修正的实际耗时 | 等待短但检查或修正耗时长，也要如实保留 |
| 返工 | 保留首次结果及每次追加指令 | 同一问题是否反复出现，修好局部后是否引入新问题 |

如果某轮首次结果有问题，先保存并记录，再在原会话中追加修正。修正后继续下一轮，并注明使用的是哪个结果；若始终无法继续，就记录中断位置，不把重新开会话的结果算成同一条连续编辑链。
