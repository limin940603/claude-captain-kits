# 一人公司接单卡片（9 张，复制就能填）

> 来源：老金《一人公司，单月收入近10万，我做了这三门生意（OPC系列-3）》（公众号「老金带你玩AI」，2026-10-31）文中的方法，克劳德队长整理成可填写的表格。表里的"示例"是我们编的演示内容，不是真实订单。
> 用法：复制到飞书文档、Notion、Excel 或任何表格里。新单来了按顺序用：先 ④ 开工三问判断值不值得做 → ⑤⑥ 摸清需求和付款路径 → ⑦ 谈付费试单 → ①③ 开工前写死 → ② ⑨ 每天看进度 → ⑧ 每周自查。

---

## ① 排期六项（每张新单开工前填）

| 项目 | 填写 | 示例 |
|---|---|---|
| 答应交什么 |  | 一份合并后的周报表 + 异常清单 |
| 谁、在何时提供材料 |  | 对方财务，周二前给脱敏样表 3 份 |
| 何时制作、何时检查 |  | 周三制作，周四上午自查 |
| 谁验收 |  | 对方财务主管 |
| 何时收款 |  | 验收当天发付款信息，3 个工作日内到账 |
| 售后到哪天 |  | 交付后 14 天内，限这一种格式 |

注意：只写"周三做完"不算排期。材料没到的那天，后面每个日期都要跟着改。

## ② 进度记录卡（每单一张，每天看一眼）

| 项目 | 填写 |
|---|---|
| 交什么 |  |
| 不交什么 |  |
| 谁确认 |  |
| 何时收款 |  |
| 现在卡哪 |  |
| 下一步谁做 |  |

注意：开发单写细，课程单可以简写。"现在卡哪"和"下一步谁做"每天更新，等对方的事写清对方是谁、约的哪天。

## ③ 开工六约定（开发单，写进合同或确认消息）

| 约定 | 写清楚 |
|---|---|
| 功能范围（这次做到哪里） |  |
| 材料谁提供、哪天给 |  |
| 部署方式（谁负责放上去） |  |
| 谁验收、怎么算通过 |  |
| 修改怎么处理（新增需求怎么报价、交期怎么改） |  |
| 维护到哪天（之后怎么收费） |  |

注意：维护单独报价，不包"随叫随到"。故障、新增功能、响应时间分开写。

## ④ 开工三问（想接一类新活之前答）

| 问题 | 我的答案 |
|---|---|
| 第一批买家在哪？（说得出具体的人或渠道） |  |
| 多久能收到钱？ |  |
| 收钱前要垫多少时间和成本？ |  |

注意：答不出买家和垫资，先别加工具、别搭平台。克劳德队长自己再多问三句：服务谁、解决什么问题、最小交付是什么。

## ⑤ 样表五问（客户喊麻烦时，先拿一份获授权的样例问）

| 问题 | 对方回答 |
|---|---|
| 用了几张表（几份材料）？ |  |
| 谁来合（谁在做）？ |  |
| 多久做一次？ |  |
| 哪里容易错？ |  |
| 错了谁补救？ |  |

注意：不用先发长问卷，顺着他最近一次真实工作问。"表、合、错"换成他的实际工作。

## ⑥ 上次怎么买（紧接着样表五问）

| 问题 | 对方回答 |
|---|---|
| 上次买类似服务，谁决定？ |  |
| 谁给材料？ |  |
| 谁确认结果？ |  |
| 钱怎么付（对公/个人、几次付、审批多久）？ |  |

注意：用来分清"喊麻烦的人"有没有付款权。喊得最急的人，未必能批预算。

## ⑦ 付费试单原话（谈小范围试单时整段发）

```
这次先只处理【这一种格式】。你提供【脱敏样表】，我交【合并结果和异常清单】。
试单价格【 】元、交付时间【 】、谁来核对【 】，咱们先说定，格式变了另谈。
```

用法：【】里换成你的交付物。试单要收钱，金额可以小，但要有；小样证明能做，不等于把完整项目免费做完。

## ⑧ 八类责任清单（每周自查一次，漏了哪摊）

| 责任 | 管什么 | 本周谁做 / 做了什么 | 漏了吗 |
|---|---|---|---|
| 方向与产品 | 卖给谁，解决什么，哪些不做 |  |  |
| 内容与获客 | 做案例，把合适的人引过来 |  |  |
| 销售与商务 | 谈需求、承诺、范围和价格 |  |  |
| 项目统筹 | 催材料、排期、处理变更 |  |  |
| 制作与质量 | 把东西做出来，检查能不能交 |  |  |
| 售后与使用 | 交接、答疑、处理约定范围内的问题 |  |  |
| 财务行政 | 跟款、票据、成本、权限与备份 |  |  |
| 复盘与协作 | 改权益、报价和测试，分任务、验收协作成果 |  |  |

注意：AI 和外协能接"制作"，但"答应什么、结果是否过关"最后还是你自己确认。

## ⑨ 任务六列（看板列名照抄）

| 等材料 | 可开工 | 制作中 | 待检查 | 待客户确认 | 已完成 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

注意：不只看哪列堆得高，还要看谁快到交期、卡了多久。"待检查"堆起来时，先少开新单、留出检查时段，别再买一个生成更快的工具。

## 附：让 AI 帮你填第一张卡

把下面这段发给任意 AI 助手，再贴上你和客户的聊天记录（先去掉对方姓名、电话等隐私）：

```
下面是我和一位客户的沟通记录。请按这 6 项帮我整理成排期表：
答应交什么、谁在何时提供材料、何时制作和检查、谁验收、何时收款、售后到哪天。
聊天里没说清的项写"待确认"，并列出我下一条消息要问对方的问题，不要替我编日期和金额。
```
