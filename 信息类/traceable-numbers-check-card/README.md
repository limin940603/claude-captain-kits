# AI 报告数字可追溯检查卡

AI 报告里的数字看起来都合理，你能逐个追到它怎么算出来的吗？材料所引的 Meta ABTest Agent 论文强调，由模型选择和排序分析流程，由确定性代码产生报告数字。这给经营分析提供了一个可借鉴的方法：先固定统计口径和评判标准，再让工具计算，并保留复算依据。本卡是我们据此整理的检查方法，尚未通过经营分析迁移实验验证，不代表所有分析 Agent 的效果保证。

## 先固定规则，再开始分析

把下面这张表填好，再交给 AI。不能确定的项目明确写“待确认”，不要让 AI 根据结果自行补定。

| 需要固定的项目 | 要写清什么 |
|---|---|
| 分析问题 | 这份报告具体要回答什么，支持哪项决定 |
| 数据范围 | 使用哪些文件、工作表、字段和数据版本 |
| 分析单位 | 按用户、订单、商品还是其他对象统计 |
| 时间范围 | 起止时间、时区，以及按创建、支付还是完成时间统计 |
| 指标定义 | 指标名称、计算公式、单位；比例指标的分子和分母 |
| 数据处理 | 重复记录、缺失值、异常值、退款及取消记录如何处理 |
| 比较方式 | 比较哪些组或时期，使用什么基准 |
| 评判标准 | 什么结果支持结论，什么情况只能判为证据不足 |

涉及实验时，还应预先写清主要指标、检验方法、判断阈值和停止条件。标准可以因合理原因修订，但必须记录原因、获得确认，并按新标准重新计算。

## 可复制检查清单

```text
AI 报告数字可追溯检查卡

【数字能否复算】
□ 每个关键数字都有明确的数据来源和定位信息。
□ 每个指标都有公式、单位和统计范围。
□ 比例指标能找到分子、分母及各自筛选条件。
□ 汇总数字能追到参与计算的记录或中间结果。
□ 计算由实际执行的工具或代码完成，并保留输出。
□ 展示值的舍入方式明确，复算使用未舍入值。
□ 报告中的关键数字均已逐项复算、核对。

【统计口径是否保持一致】
□ 分析前已固定时间范围、分析单位和指标定义。
□ 分组与比较使用一致的筛选和计算规则。
□ 去重、缺失值、异常值等处理有记录。
□ 没有未经确认删除“不好看”的数据。
□ 没有把不同分母或不同时间范围的结果直接比较。
□ 口径发生变化时，保留变更原因、确认记录和重算结果。

【评判标准是否预先固定】
□ 看结果前已明确要回答的问题和主要指标。
□ 判断阈值、比较基准等规则已提前记录。
□ 没有看到结果后再挑有利指标充当主要依据。
□ 探索中发现的线索与按预定标准得出的结论分开标注。
□ 证据不足时明确写“不足以判断”。
□ 描述性差异没有直接写成因果结论。

【报告是否如实说明执行状态】
□ 原始数据、工具计算结果、解释和建议能够区分。
□ 未执行的计算没有写成“已验证”。
□ 工具失败、数据缺失和无法复算的数字均已标明。
□ 结论引用的是已核对的数字。
```

## 给每个关键数字留一行底稿

同一个指标在不同组别、时期或筛选条件下出现，应分别记录。

| 报告位置／指标 | 数据来源与定位 | 口径及筛选条件 | 公式／代码定位 | 工具执行结果 | 展示值与舍入规则 | 复算状态 |
|---|---|---|---|---|---|---|
| 待填写 | 待填写 | 待填写 | 待填写 | 待填写 | 待填写 | 待核对 |

“来源：销售数据”还不足以复算。应进一步说明使用哪个数据版本、哪些字段、什么时间范围，以及如何筛选和汇总。

## 可直接发给 AI 的约束提示词

```text
请分析我提供的数据，生成一份数字可追溯的报告。

先不要计算。请先列出分析问题、数据范围、分析单位、
时间范围、指标公式、数据处理规则、比较方式和评判标准。
沿用我已经明确的规则；缺失且会影响结论的规则，请先询问。
规则确认后再执行分析。

你的职责是安排分析步骤、调用工具并解释结果。
报告中的计算数字必须来自实际执行的计算工具或代码。
不得凭语言推断补出数字，不得把预计结果写成执行结果。
如果无法调用工具，请交付待执行方案，不要声称已经算完。

执行过程中：
- 保留原始数据，不直接覆盖。
- 记录数据版本、字段、筛选条件和处理步骤。
- 不得未经确认改变指标、分母、时间范围或评判标准。
- 如需变更规则，说明原因和影响，等待确认后重算。
- 保留代码或计算步骤，以及实际执行输出。

交付时请提供：
- 分析结论，并标明依据的指标。
- 每个关键数字的计算底稿，包括来源、口径、公式、
  工具输出、展示值、舍入规则及复算状态。
- 按相同数据和规则重新执行的复算结果。
- 数据缺失、执行失败、口径变更和证据不足的记录。

区分按预定标准得到的结论与探索性发现。
不要把相关性或组间差异直接解释为因果关系。
无法复算的数字标记为“待核对”，不作为已验证结论的依据。
```
