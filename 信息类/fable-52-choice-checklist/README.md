# Claude Fable 5.2 选型判断清单：这件活该不该交给 Fable

> 克劳德队长 · 评论「清单」领取的那份
> 对应文章：《Claude Fable 5.2发布：跑分、案例、价格一次看懂》
> 用法：手上有一件活，先过「一、五个问题」，再照「二、分工表」选模型；Pro / Max 用户按「三」把这周的福利用掉。
> 依据：Anthropic 官网发布公告、平台文档、会员促销说明和官方选型博客（2026-11-09 起，链接见文末）。价格、额度、截止时间以官方最新说明为准。

## 一、五个问题：这件活值不值得上 Fable

Fable 5.2 的 API 价格是 Opus 5.5 的 2 倍。官方建议：大多数写代码和知识类的活先用 Opus 5.5，遇到最难的技术项目再切 Fable。下面五问帮你判断。

### 1. 用 Opus 5.5 认真试过了吗？
- 没试过 → **先用 Opus 5.5**。
- 试过，结果不够好 → 看第 2 问。

### 2. 调高思考强度（effort）了吗？
官方原话：换模型之前，先试试调高思考强度。
- 还没调 → 先把 Opus 5.5 的思考强度调高再跑一次。
- 调到最高还是不行 → 看第 3 问。

### 3. 它是不是这三类"硬骨头"？
- [ ] 超难推理：数学证明、物理问题、复杂工程方案
- [ ] 新项目从零规划、大架构设计
- [ ] 卡了很久、换了几种问法都解决不了的疑难问题

一条都不沾 → 留在 Opus / Sonnet。沾一条以上 → 看第 4 问。

### 4. 是不是要连续跑几小时、指挥一群子智能体的长任务？
- 是 → Fable 当**总指挥**（拆任务、协调、检查别人的活），Opus / Sonnet 当**干活的**。官方展示的 8 天造操作系统、30 小时形式化费马大定理都是这种用法。
- 否，只是单次问答 → 多半不值 2 倍价，回到 Opus。

### 5. 能不能只在关键节点用它？
Claude Code 里可以让 Fable 当「顾问」（Advisor）：便宜的模型平时干活，到关键节点（定方案前、卡在同一个错误上、宣布完成前）再请教 Fable。
- 输入 `/advisor` 设置。官方实验功能，只在 Anthropic 官方 API 上可用；用 Fable 当顾问可能按额外用量计费，开之前看一眼提示。

## 二、分工表（我们的建议，复制到你的笔记里）

| 你的活 | 用谁 |
|---|---|
| 聊天、改文案、查资料、写周报 | Sonnet 5.5 或 Opus 5.5 |
| 日常写代码、修 bug、做功能 | Opus 5.5（先把思考强度往上调） |
| 新项目从零规划、大架构设计 | Fable 5.2 |
| 卡了很久的疑难问题 | Fable 5.2 |
| 一堆智能体并行干的长任务 | Fable 5.2 当总指挥，Opus / Sonnet 当干活的 |
| 网络安全 / 生物方向被 5.1 误拦过的请求 | 可以再用 Fable 5.2 试试（官方早期测试：不必要拦截少约 55%） |

**价格速查（每百万 token，官方价）**

| | 输入 | 输出 | 备注 |
|---|---|---|---|
| Fable 5.2 | $8 | $40 | 上一代 5.1 是 $10 / $50 |
| Fable 5.2 快速模式 | $16 | $80 | 最多约 2.5 倍出字速度 |
| Opus 5.5 | $4 | $20 | |

上下文 100 万 token，单次最长输出 12.8 万 token，知识截止 2026 年 6 月（半年内的新闻要配合联网）。

**Fable 还是 Mythos？** 两者是同一个底层模型，区别只在安全设置。Mythos 5.2 只给通过 Anthropic 网络安全或生命科学验证计划的机构用；普通用户和绝大多数开发者用 Fable 就够了。

## 三、会员这周的福利，按身份打勾

### Pro 和 Team 标准席位（截止美国时间 11 月 16 日 23:59）
- [ ] 在对话框的**模型选择里手动选 Fable 5.2**（默认模型不会自动变）
- [ ] 知道这周最多可以拿**一半的周额度**跑 Fable，不额外收费
- [ ] 另送的 1 次 Fable 额度重置，在「设置 → 用量」里点
- [ ] 挑出手上**最难的一件事**丢给它（卡了很久的方案、想做没做的项目规划），别拿来聊天
- [ ] 过了截止时间，再用就走额外用量计费

### Max、Ultra 和 Team 高级席位（2027 年 3 月 8 日前用掉）
- [ ] 去「设置 → 用量」看送了几次 Fable 额度重置：订阅不满 6 个月 1 次，6～12 个月 2 次，满 12 个月 3 次
- [ ] 把重置留给真正的长任务，别在日常问答里耗掉

### API 用户
- [ ] 别直接把默认模型换成 Fable
- [ ] 先用 Opus 5.5 跑、调思考强度；真不够，再在关键环节换 Fable
- [ ] 换之前用同一批真实任务对比两边的结果和账单

免费版没有这次福利。

## 四、可以直接发给 AI 的提示词

```
我手上有一件活：【描述这件活，越具体越好，包括已经试过什么】。
我能用的模型：【例：Claude Pro 会员 / Claude Code + API】。
请按下面顺序帮我判断要不要用 Claude Fable 5.2：
1. 这件活是不是超难推理、从零规划大架构、长期卡住的疑难问题，或要指挥多个子智能体连续跑几小时的长任务？逐条回答是/否并说理由。
2. 如果都不是，告诉我用 Sonnet 5.5 还是 Opus 5.5，以及思考强度建议调到哪一档。
3. 如果值得用 Fable，告诉我哪一步交给 Fable、哪些步骤交给 Opus / Sonnet 去做，尽量只在关键节点用 Fable。
4. 估一下大概的成本差异，按官方价：Fable 5.2 输入 $8 / 输出 $40，Opus 5.5 输入 $4 / 输出 $20（每百万 token）。
拿不准的地方先问我，不要自己假设。
```
