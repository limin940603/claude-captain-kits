# Claude 不封号自查清单（11 月版）

> 克劳德队长 · 评论「清单」领取的那份
> 对应文章：《史上最全：Claude 封号 3 大原因 + 3 个危险信号》
> 用来做什么：对照官方条款，逐条查自己的用法有没有踩线；被封了按顺序处理。
> 用法：复制第 3 节清单逐条打勾；拿不准就把第 6 节那段话发给你的 AI 助手，让它帮你判断。
> 规则会变，以下面「官方原文」里的页面为准。

---

## 1. 官方写明的封号原因（3 类）

1. 反复违反使用政策（Usage Policy）
2. 从不支持的地区创建账号
3. 违反服务条款（Terms of Service）

## 2. 2026-11-12 起，这 3 种都算「不支持地区」

- 人在不支持的地区时使用（哪怕账号属于支持地区的公司）
- 公司注册地或总部在不支持的地区
- 公司被不支持地区的个人或企业控股

中国大陆、香港、澳门不在支持名单内。

## 3. 自查清单（复制到你的笔记里逐条打勾）

```
- [ ] 人在支持地区使用
- [ ] 18 岁以上，本人注册、本人使用
- [ ] 不共享、不借号、不买号（合租号、拼车号、成品号都算）
- [ ] 付款用本人真实、完整的账单信息
- [ ] 要自动化就走 API Key，不用脚本操作网页版
- [ ] 不转售服务或额度
- [ ] 收到使用政策警告就停下自查
- [ ] 被要求年龄或身份验证时，用本人证件原件配合
```

## 4. 3 个危险信号

| 信号 | 意味着什么 | 该做什么 |
|---|---|---|
| 收到使用政策警告 | 已经被判定踩线，继续会封 | 停下，查最近用法；觉得误判就按官方说明申诉 |
| 被要求验证年龄 | 系统怀疑未满 18 岁，会先停用 | 走第三方 Yoti 验证恢复 |
| 被要求实名验证 | 需要证件原件 + 现场自拍（Persona） | 用本人证件；截图、复印件、电子证件都不收 |

## 5. 已经被封，按这个顺序

1. 用被封的账号登录 claude.ai，填申诉表（不登录看不到）。
2. 同一页面可以导出数据或删除账号，先导出重要对话。
3. 因违反使用政策被禁用的邮箱，不能再注册新账号。
4. 因违约被终止的订阅，不退款。

## 6. 发给 AI 帮你查（可选）

```
下面是我目前使用 Claude 的方式：<写清：人在哪、账号谁注册的、怎么付款、是否多人共用、是否用脚本>。
请对照这份清单逐条判断：哪条已经满足、哪条有风险、风险条怎么改。只依据清单内容，不要猜测官方没写的规则。
```
